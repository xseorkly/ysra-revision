A · Applications

Application \(f:E\to F\)chaque x de E a une et une seule image f(x) dans F
Antécédent de yun x tel que f(x) = y ; il peut y en avoir 0, 1 ou plusieurs
\(F^E\)l’ensemble des applications de E dans F (\(p^n\) éléments si |E| = n et |F| = p)
f = gmême départ, même arrivée, et f(x) = g(x) pour tout x
Restriction \(f_{|A}\)même règle, sur un départ plus petit A ⊂ E (unique)
Prolongementdépart plus grand, les anciennes valeurs sont gardées et les nouvelles choisies (pas unique)
Image directe\(f(A)=\{f(x)\,/\,x\in A\}\) : où atterrit A
Image réciproque\(f^{-1}(B)=\{x\in E\,/\,f(x)\in B\}\) : qui atterrit dans B (existe toujours, peut être ∅)
Composée\(g\circ f(x)=g(f(x))\) : d’abord f, puis g ; en général \(g\circ f\neq f\circ g\)
Dérivée d’une composée\((g\circ f)'(x)=f'(x)\,g'(f(x))\)
Réciproque \(f^{-1}\)\(f^{-1}\circ f(x)=x\) et \(f\circ f^{-1}(y)=y\) ; courbes symétriques par rapport à y = x ; on la trouve en isolant x dans y = f(x)
⚠️\(f^{-1}\) (réciproque) n’est pas \(\frac1f\) (inverse) ; on écrit \(f^{-1}(\{y\})\) pour les antécédents de y

B · Propriétés des fonctions réelles

PaireD symétrique et f(−x) = f(x) : symétrie par rapport à l’axe des ordonnées
ImpaireD symétrique et f(−x) = −f(x) : symétrie par rapport à l’origine ; f(0) = 0 si f est définie en 0
T-périodiquef(x + T) = f(x) pour tout x : le motif se répète tous les T
Croissante sur Ia ≤ b ⇒ f(a) ≤ f(b) (l’ordre est conservé) ; strictement : a < b ⇒ f(a) < f(b)
Décroissante sur Ia ≤ b ⇒ f(a) ≥ f(b) (l’ordre est renversé)
Majorée / minorée∃M, ∀x, f(x) ≤ M / ∃m, ∀x, f(x) ≥ m ; bornée = les deux
Maximum / minimumun majorant / minorant atteint par f
sup / infle plus petit des majorants / le plus grand des minorants ; s’il est atteint, c’est le max / le min
Exemple clé\(\frac1x\) sur \(\mathbb R^{+*}\) : inf = 0, pas de minimum, pas majorée
Axe x = a\(f(a+h)=f(a-h)\) pour tout h (exercice 05.2 du prof)
Centre Ω(a ; b)\(f(a+h)+f(a-h)=2b\) pour tout h ; souvent au croisement des asymptotes
Bornéeil suffit de montrer \(|f(x)|\leqslant K\) : on majore le haut et on minore le bas d’une fraction (05.5)
Prouver inf = m① m est un minorant ; ② pour tout \(m'>m\), on trouve x avec \(f(x)\lt m'\) (05.6)

Les limites à connaître

Bords\(\ln x\to-\infty\) en \(0^+\), \(+\infty\) en \(+\infty\) ; \(e^x\to0\) en \(-\infty\), \(+\infty\) en \(+\infty\) ; \(\frac1x\to\pm\infty\) en \(0^\pm\), 0 en \(\pm\infty\)
Croissances comparées\(\frac{\ln x}{x}\to0\) (en \(+\infty\)) ; \(x\ln x\to0\) (en \(0^+\)) ; \(\frac{e^x}{x}\to+\infty\) (en \(+\infty\)) ; \(xe^x\to0\) (en \(-\infty\)) ; \(\frac{\sqrt x}{x}\to0\) (en \(+\infty\))
Le classementen \(+\infty\) : \(\ln x\ \ll\ x^\alpha\ \ll\ e^x\). L’exponentielle gagne toujours, le logarithme perd toujours
Taux d’accroissement\(\frac{\ln(1+x)}{x}\to1\) et \(\frac{e^x-1}{x}\to1\) quand \(x\to0\)
Partie entièreen un entier k : \(k-1\) à gauche, k à droite

Les 12 erreurs qui coûtent des points

  1. Dire « l’antécédent » alors qu’il peut y en avoir plusieurs, ou aucun.
  2. Calculer f(A) avec f(a) et f(b) quand f n’est pas monotone sur A. Avec x² : f([−1 ; 2]) = [0 ; 4].
  3. Écrire \(f^{-1}(x)\) pour les antécédents, ou confondre \(f^{-1}\) et \(\frac1f\).
  4. Composer dans le mauvais ordre : \(g\circ f\) = f d’abord.
  5. Oublier le domaine (ln, √, dénominateur) avant de composer, de résoudre ou de dériver.
  6. Oublier de vérifier que le domaine est symétrique avant de parler de parité.
  7. Dire que \(\frac1x\) est décroissante sur ℝ*.
  8. Confondre sup et max : le sup n’est pas forcément atteint.
  9. Ent(−2,3) = −3, et non −2.
  10. \(\sqrt{a+b}\neq\sqrt a+\sqrt b\), \(\ln(a+b)\neq\ln a+\ln b\), \(e^{a+b}\neq e^a+e^b\).
  11. Oublier le facteur u′ : \((e^{3x})'=3e^{3x}\), \((\ln(2x))'=\frac1x\).
  12. Dériver \(2^x\) comme \(x^2\) : \((2^x)'=\ln2\cdot2^x\).
